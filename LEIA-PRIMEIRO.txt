SYNAPSE DISCOVERY 1.0 RC1 — CLOUDFLARE + GITHUB

CORREÇÃO 1: inclui validação de respostas do servidor e recuperação da tela de erro.
Para configurar tudo no Windows, siga docs/CLOUDFLARE.md a partir do passo 1.
O guia também explica o diagnóstico do erro "Cannot read properties of undefined (reading 'map')".

1. Leia README.md e docs/CLOUDFLARE.md.
2. Use Cloudflare Workers, D1 e R2 privado. Não publique apenas web/ no Pages.
3. Configure o banco, o bucket e a origem HTTPS no wrangler.jsonc.
4. Envie o conteúdo desta pasta ao GitHub: package.json e wrangler.jsonc devem ficar na raiz.
5. No Worker conectado ao GitHub: build = npm run build; deploy = npm run deploy.
6. Configure os secrets e serviços reais conforme o guia.
7. Abra /instalar para criar o responsável, confirme e-mail e configure 2FA em /admin.
8. Conclua a validação em /operacao e /admin antes de abrir os cadastros.

Se já tem dados da versão Python, siga docs/MIGRACAO.md ANTES de criar outra conta administrativa.
Nunca envie .env, .dev.vars, .private, bancos, mídias privadas ou backups ao GitHub.

O pacote está preparado para configurar e instalar. A abertura geral ainda depende da hospedagem e das integrações reais. Há diferenças de recursos em relação à edição Python: consulte docs/RESULTADOS-1.0.md.
