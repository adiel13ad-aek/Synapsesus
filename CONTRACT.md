# Internal implementation contract
Native Cloudflare Worker ES modules, no TypeScript. Existing source in legacy/ is authoritative for API shape. Preserve frontend web/ and original data schema generated to migrations/0001_initial.sql. Root owns src/core.js src/index.js and schema generation.
Each module exports default function register(router) { router.on('GET','/api/path/:id',async c=>{...; return {...};}); }. c={request,env,ctx,url,params,user,sessionHash,headers,json(),db}. db helper via exported functions.
Imports from ./core.js: HttpError(status,message), fail(status,message), uid() 32hex, now() ISO, stamp() seconds, sha256(string), token(n=32) base64url, equal(a,b), query(c,sql,...args) array, first(c,sql,...args) row|null, run(c,sql,...args) D1Result, batch(c,[[sql,...params],...]) transactional, json(c) parsed object cached <=100k except media image payloads 5MB, text(value,min,max,label) trims, bool(value), email(value), safeURL(value,optional=false), needUser(c) -> c.user or 401 (also checks CSRF for writes via global router), requireSocial(c) async account ready/email/age/terms and maintenance, publicActor(a), canViewAuthor(c,authorId,viewerId), visiblePost(c,id), blocked(c,a,b), settings(c), termsVersion(c), socialStatus(c), rate(c,key,max,seconds), log(c,userId,action,subject,summary), hashPassword(password) / passwordOK(password,encoded), setSession(c,userId), clearSession(c), issueToken(c,user,purpose), persistImage(c,data,ownerId) -> /media/id.ext in R2 with asset row, removeMedia(c,path), sendMail(c,to,subject,body) -> queue row.
Core owns shared auth/session/crypto/media helper implementations. Runtime response supports object or Response; c.headers appended globally e.g. Set-Cookie. DB binding env.DB; bucket env.MEDIA; env.ASSETS static.
Safety agent exports launchReadiness(c) checks {ready,checks}, processMail(c) for scheduled, register safety/support/operations routes. Core socialStatus requires email_verified, adult + unexpired signed receipt (AGE_ENFORCED=0 only local APP_ENV=development). Minor features remain disabled. Existing frontend expects status strings.
Admin agent exports requireAdmin(c,ownerOnly=false) validates operator role and session elevation 2FA. Admin table schema unchanged; no default password, bootstrap via one-time secret route in auth module, needs admin 2FA afterwards. No permanent bypass production.
Auth agent registers auth/preferences/account routes incl bootstrap and /api/state NOT owned by auth. Auth calls core helpers issueToken/setSession.
Social agent owns /api/state,/api/posts,/api/feed,/api/messages,/api/links,/api/search,/api/stories,/api/notifications,/api/media and /media, profile, follow/block, reports. Safety owns follower approval and security centre. Disable unsupported video/push/calls capabilities honestly (retained in legacy).
Admin agent owns /api/admin/* except /api/admin/operations* /api/admin/support* /api/admin/integrations* /api/admin/backups* which safety owns. Own public pages rendered from legacy/launch.py templates, policies, /admin,/bem-vindo,/como-funciona,/ajuda,/robots.txt,/sitemap.xml. Root static routes /conta/seguranca /operacao mapping.
All SQL parameter bound. Never expose password_hash, encrypted 2FA seeds, tokens, email of other accounts. R2 bucket private authenticated reads, Cache-Control private,no-store. No broad DM read endpoint admin.
